Inspect this Windows computer locally

This mode does not send targets, ports, or results to the website or PHP server. The PowerShell script reads the computer's current TCP listening sockets and creates a local HTML report.

Why a script? A browser page cannot directly read local TCP listeners. Browser security intentionally blocks that access. The included PowerShell script runs entirely on your computer.
Download local-scanner.ps1

How to run

  1. Download local-scanner.ps1.
  2. Right-click the file and choose Run with PowerShell.
  3. If Windows blocks scripts, open PowerShell in that folder and run:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\local-scanner.ps1

The bypass applies only to that process. The script opens a report named local-ports-DATE.html beside the script.

What local mode shows

  • TCP ports actually listening on this computer.
  • Listening address and exposure scope.
  • Likely service name for common ports.
  • Process ID and process name when Windows permits access.
  • No cloud upload and no request to scan.php.
Remote mode originates from the PHP server. Local mode runs only on the Windows computer.
