    Inspect this Windows computer

    A web page cannot read the ports your computer is listening on, so a small PowerShell script does it. It runs only on your machine and sends nothing anywhere.

    Download launcher Download script
    1. Save both files in the same folder.
    2. Double-click Run-local-scan.bat.
    3. The report opens in your browser and is saved next to the script.

    Prefer a terminal? Run powershell -NoProfile -ExecutionPolicy Bypass -File .\local-scanner.ps1. Add -CaptureSeconds 30 in an administrator window to record traffic.

    What the report shows

    Ports and connections
    Every listener and open socket, with the process that owns it and how exposed it is.
    Findings
    A short list of what to look at first, ranked high, medium and info.
    Network and hosts file
    Adapters, routes, DNS, neighbours and active hosts entries.
    Firewall
    Profiles and inbound rules, marking broad rules and rules for ports that are listening.
    Traffic capture
    Optional capture that you can open in Wireshark.
